7) Security & privacy

RBAC: Employee can only see own records; forbid cross-employee queries.

PII hygiene: Mask IBAN in UI except last 2–4; never show AFM fully in dashboard cards.

Device safety: Show login devices & last login (self-service revoke).

Audit: Log downloads of payslips (who/when/IP).

8) Edge cases & states

No schedule: hide card; keep a compact “No upcoming shifts” stub.

Unapproved timesheets: hours show with amber badge; CTA “Fix now”.

Late payroll: show “Running late” pill + link to employer note.

On leave today: display banner with return date.

Multiple employments (multi-tenant/role): context switcher at top (“Property • Role”).

Terminated (access window): read-only dashboard for 60–90 days; only payslip download & tax docs.
