1) You’re running the dev server in deploy

This line gives it away:

[Boot] 🎯 Setting up development SPA routing with Vite


So the catch-all is Vite-dev, not your static build.

Fix (Replit Deploy)

Set NODE_ENV=production in Replit Secrets (or Deploy env).

Make Deploy run a prod command, not npm run dev.
Example:

# Build client first, then start server in prod
npm --prefix client ci && npm --prefix client run build \
&& npm ci && npm run build:server \
&& NODE_ENV=production node dist/index.js


(Use your real server build step if different.)

After redeploy, you should see:

[Boot] 🎯 Setting up production SPA routing with static assets

2) Rate-limit validation error (IPv6)

You’re getting:

ERR_ERL_KEY_GEN_IPV6: Custom keyGenerator appears to use request IP without ipKeyGenerator


This can short-circuit middleware init.

Fix your limiter
// BEFORE creating the limiter
import { rateLimit, ipKeyGenerator } from 'express-rate-limit';

// ...

const loginLimiter = rateLimit({
  windowMs: 60_000,
  max: 5,
  standardHeaders: true,
  legacyHeaders: false,
  keyGenerator: (req) => {
    // Trust proxy is already set, so req.ip is good —
    // but use ipKeyGenerator to satisfy IPv6 validation.
    return ipKeyGenerator(req);
  },
  // keep your existing handler/requestWasSuccessful if you want
  handler: (req, res) => res.status(429).json({ error: 'rate_limited', retryAfterSec: 60 }),
});

3) CSP: allow your app to actually load

Your current Helmet CSP is very tight (no font-src, limited connect-src). That can blank the UI.

Safer CSP (prod/dev aware)
const isProd = process.env.NODE_ENV === 'production';

app.use(helmet({
  frameguard: { action: 'deny' },
  referrerPolicy: { policy: 'no-referrer' },
  contentSecurityPolicy: {
    useDefaults: true,
    directives: {
      "default-src": ["'self'"],
      "script-src": isProd ? ["'self'"] : ["'self'", "'unsafe-eval'"],
      "script-src-elem": isProd ? ["'self'"] : ["'self'", "'unsafe-eval'"],
      "style-src": ["'self'", "'unsafe-inline'"],
      "img-src": ["'self'", "data:", "blob:"],
      "font-src": ["'self'", "data:"],
      "connect-src": [
        "'self'",
        ...(process.env.CSP_CONNECT_SRC?.split(',').map(s => s.trim()).filter(Boolean) ?? []),
      ],
      "worker-src": ["'self'", "blob:"],
    },
  },
}));


Then set CSP_CONNECT_SRC to any external APIs your frontend calls (Supabase, Sentry, etc.).
