6) GL API (Generic, for any ERP)
6.1 Endpoints (REST)
POST   /v1/gl/mappings            # create/update map rules
GET    /v1/gl/mappings            # list current mappings
POST   /v1/gl/journals/build      # build journal for run_id (returns draft)
POST   /v1/gl/journals/{id}/post  # lock & mark posted; emits webhook
POST   /v1/gl/journals/{id}/reverse # auto-create reversing journal
GET    /v1/gl/journals/{id}
GET    /v1/gl/journals?period=YYYY-MM&entity_id=...

6.2 Mapping Rule (example)
{
  "entity_id": "PRINCESS_SA",
  "rules": [
    { "type": "earning", "code": "REG", "account": "60.00.100", "dimension": "cost_center=property" },
    { "type": "earning", "code": "OT_TIER1_40", "account": "60.03.110" },
    { "type": "premium", "code": "NIGHT_25", "account": "60.01.120" },

  "split_by": ["property_id","department"], 
  "rounding": "bankers",
  "collapse_zero_lines": true

6.4 Error Model
{ "error": "MAPPING_MISSING", "detail": "No GL account for earnings code NIGHT_25", "hint": "Create mapping in /gl/mappings" }

6.5 Idempotency

Include Idempotency-Key on POST /gl/journals/*. Repeating with same key returns the same journal/post result.
