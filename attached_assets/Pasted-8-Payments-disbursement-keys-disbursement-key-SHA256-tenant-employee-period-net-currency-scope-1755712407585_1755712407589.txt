8) Payments & disbursement keys

disbursement_key = SHA256(tenant|employee|period|net|currency|scope_id)

Guardrails: cannot issue a second payment for the same key unless previous is explicitly canceled/superseded.

Payment batches can be created:

Per scope (immediate payouts), or

Merged (later batching) by selecting finalized scope lines.

9) GL & reporting

Per-scope journal: date = scope.finalized_at, dimensions include scope_id and sequence.

Consolidated journal: optional at period close; sums per natural account/cost center.

Reports: show Coverage (processed employees / total eligible), list unprocessed.

10) Edge cases & guards

Mixed calendars/entities: block scope creation; show which employees conflict.

Pending approvals: show count; allow proceed (unapproved hours treated as zero) or require approval first (tenant setting).

Missing bank/AFM: allow payroll calc but hold payments; badge in scope summary.

Cap overflow: if remaining cap = 0, amounts over cap routed to uncapped buckets (per Greek rules); narrative explains.

Recalc after ruleset change: scopes already finalized remain immutable; new scope uses new version and shows delta.

Terminated re-hires same month: treat as separate contract; ensure caps/reset behavior per law (configurable).

Zero-net slips: create payslip, no payment line.

11) Performance targets

Compute 50 employees scope: p95 ≤ 1.2s.

Finalize (PDFs + ledger write): p95 ≤ 2.0s.

Consolidate APD/ΦΜΥ for 300 employees: p95 ≤ 1.5s.
