Fix = route order + smarter catch-all so /assets/* (and API, health, etc.) bypass it.

Here’s a clean, copy-paste setup for both dev (Vite middleware) and prod (built assets).

DEV (Vite server as middleware)
// server/dev.ts (or inside your server bootstrap when NODE_ENV!=='production')
import express from 'express';
import history from 'connect-history-api-fallback';
import { createServer as createViteServer } from 'vite';

export async function attachDev(app: express.Express) {
  const vite = await createViteServer({ server: { middlewareMode: true } });

  // 1) API routes FIRST
  // app.use('/api', apiRouter);

  // 2) History fallback, but DO NOT rewrite assets or API/health/etc.
  app.use(
    history({
      htmlAcceptHeaders: ['text/html', 'application/xhtml+xml'],
      disableDotRule: true,
      rewrites: [
        // keep these as real files
        { from: /^\/assets\/.*$/, to: (ctx) => ctx.parsedUrl.path! },
        { from: /^\/favicon\.ico$/, to: (ctx) => ctx.parsedUrl.path! },
        { from: /^\/robots\.txt$/, to: (ctx) => ctx.parsedUrl.path! },
        // keep API/health untouched
        { from: /^\/api\/.*$/, to: (ctx) => ctx.parsedUrl.path! },
        { from: /^\/health$/, to: (ctx) => ctx.parsedUrl.path! },
      ],
    })
  );

  // 3) Vite middlewares AFTER history (so real files & API passed through)
  app.use(vite.middlewares);
}


Key points:

history() goes before vite.middlewares

rewrites exclude /assets/*, /api/*, /health, etc.

PROD (serve built files)
// server/prod.ts
import path from 'path';
import express from 'express';
import fs from 'fs';

export function attachProd(app: express.Express) {
  const root = path.resolve();
  const distDir = path.join(root, 'client', 'dist'); // adjust if different
  const assetsDir = path.join(distDir, 'assets');

  // 1) API FIRST
  // app.use('/api', apiRouter);

  // 2) Static assets BEFORE catch-all
  app.use('/assets', express.static(assetsDir, { maxAge: '1y', immutable: true }));
  app.use(express.static(distDir, { maxAge: '0' })); // index.html et al: no-cache

  // 3) Smart catch-all: serve index.html for client routes,
  //    but DO NOT intercept assets, api, health, etc.
  app.get(/^\/(?!api\/|assets\/|health$|favicon\.ico$|robots\.txt$).*/, (req, res) => {
    const indexPath = path.join(distDir, 'index.html');
    if (!fs.existsSync(indexPath)) {
      return res.status(500).send('index.html missing in dist');
    }
    res.sendFile(indexPath);
  });
}


Why this works:

/assets/* is mounted before the catch-all, so static files win.

The regex excludes api, assets, health, and a couple of root files.

index.html is served only for real SPA routes.

App entry (switch by NODE_ENV)
import express from 'express';
import { attachDev } from './dev';
import { attachProd } from './prod';

const app = express();

// Health & misc
app.get('/health', (_req, res) => res.json({ status: 'ok' }));

// Your API router(s) here, BEFORE front-end middleware
// app.use('/api', apiRouter);

if (process.env.NODE_ENV === 'production') {
  attachProd(app);
} else {
  attachDev(app);
}

const port = process.env.PORT || 3000;
app.listen(port, () => console.log(`server on :${port} (${process.env.NODE_ENV})`));

Optional Vite tweaks (helps avoid 404 on assets)

Ensure Vite builds where the server expects:

// vite.config.ts
export default defineConfig({
  build: { outDir: 'client/dist', assetsDir: 'assets' },
  // base: '/', // keep default unless deploying under a subpath
});

Quick verification (after deploy)
# HTML for /
curl -I https://your-app/ | grep -i content-type

# HTML for an SPA route (served by catch-all)
curl -I https://your-app/dashboard | grep -i content-type

# A real asset (should be application/javascript, not HTML)
curl -I https://your-app/assets/index-*.js | grep -i content-type

# API untouched
curl -I https://your-app/api/whatever

# Health untouched
curl https://your-app/health


Expected:

/ and /dashboard → text/html

/assets/*.js → application/javascript (or text/javascript)

/api/* → your JSON/401/etc.

/health → { "status": "ok" }

Common pitfalls to avoid

A blanket app.use('*', handler) placed before static mounting (it will eat assets).

Mounting vite.middlewares after a greedy catch-all without history() rewrites.

Serving the wrong directory (e.g., building to dist/public but serving client/dist).

Not excluding /assets in your regex or history rewrites.
