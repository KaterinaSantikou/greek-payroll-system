our Vite config explains the mismatch. You’re building the app to:

root: client/

outDir: dist/public

assets: dist/public/assets/*

index.html: dist/public/index.html

If your server is still serving client/dist (or a generic dist) the SPA will never load. Fix the server paths and the catch-all to match dist/public exactly, and don’t let the catch-all swallow /assets/*.

What to change on the server
// server/index.ts (or wherever you wire Express)
import express from "express";
import path from "path";
import fs from "fs";

const app = express();
const root = path.resolve();                     // project root
const distDir = path.join(root, "dist", "public"); // <-- matches Vite outDir
const assetsDir = path.join(distDir, "assets");

// 1) Health & API FIRST
app.get("/health", (_req, res) => res.json({ status: "ok" }));
// app.use("/api", apiRouter);

// 2) Static files BEFORE catch-all (and point at dist/public)
app.use("/assets", express.static(assetsDir, { maxAge: "1y", immutable: true }));
app.use(express.static(distDir, { maxAge: "0" })); // serves index.html, favicon, etc.

// 3) Smart catch-all for SPA routes (exclude assets/api/health/etc.)
app.get(
  /^\/(?!api\/|assets\/|health$|favicon\.ico$|robots\.txt$).*/,
  (_req, res) => {
    const indexPath = path.join(distDir, "index.html");
    if (!fs.existsSync(indexPath)) {
      return res.status(500).send("index.html missing in dist/public");
    }
    res.sendFile(indexPath);
  }
);

// 4) (Optional) trust proxy if you set secure cookies
// app.set("trust proxy", 1);

const port = process.env.PORT || 3000;
app.listen(port, () => {
  console.log("Has index?", fs.existsSync(path.join(distDir, "index.html")));
  console.log("Has assets dir?", fs.existsSync(assetsDir));
  console.log(`Server on :${port}`);
});

Build/Run command (important order)

Make sure you build before starting the server, so dist/public/index.html actually exists:

# example
npm --prefix client ci && npm --prefix client run build && npm ci && node server/index.js

Quick sanity checks after deploy
# Should be HTML
curl -I https://your-app/ | grep -i content-type
curl -I https://your-app/dashboard | grep -i content-type

# Should be JS (NOT HTML)
curl -I https://your-app/assets/*.js | grep -i content-type

# API/health still OK
curl https://your-app/health

Notes specific to your Vite config

Your config builds to dist/public — keep it; just make the server match it (above).

root: path.resolve(import.meta.dirname, "client") is fine with your aliases.

You don’t need to set base since you deploy at /.

The Replit plugins are gated out in production (NODE_ENV === 'production'), so they won’t affect prod.

If you still see a white screen, open DevTools → Network:

/assets/*.js must be 200 and application/javascript.

If you see Unexpected token '<' for a JS file, the catch-all is still serving HTML for assets → recheck the mount order and the regex.
