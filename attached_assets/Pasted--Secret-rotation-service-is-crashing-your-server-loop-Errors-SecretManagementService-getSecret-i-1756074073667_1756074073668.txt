) Secret rotation service is crashing your server loop

Errors:

SecretManagementService.getSecret is not a function

SecretManagementService.getSecretMetadata is not a function

stack from AutomatedSecretRotationService.*

What this means

Your code is calling methods on SecretManagementService that don’t exist at runtime (export/import mismatch, using a class without instantiating it, or wrong default/named import after bundling).

Fastest stabilizing fix (do all 3)

A) Add a feature flag to disable the whole subsystem in prod until it’s wired

// before scheduling the rotation
if (process.env.ENABLE_SECRET_ROTATION !== 'true') {
  console.log('[secrets] Secret rotation disabled by env');
} else {
  setInterval(() => safeRotateSecrets(), 60_000); // example
}


Set ENABLE_SECRET_ROTATION=false in Replit env. This prevents the repeating exceptions that can interfere with serving your SPA.

B) Normalize the import/export
Pick one pattern and stick to it:

If you meant named functions:

// secretManagementService.ts
export async function getSecret(name: string) { ... }
export async function getSecretMetadata(name: string) { ... }

// AutomatedSecretRotationService.ts
import { getSecret, getSecretMetadata } from '@/services/secretManagementService';


If you meant a class instance:

// secretManagementService.ts
export class SecretManagementService {
  async getSecret(name: string) { ... }
  async getSecretMetadata(name: string) { ... }
}
export const secretManagementService = new SecretManagementService();

// AutomatedSecretRotationService.ts
import { secretManagementService } from '@/services/secretManagementService';
// use secretManagementService.getSecret(...)


If you exported default:

// secretManagementService.ts
export default {
  async getSecret(name: string) { ... },
  async getSecretMetadata(name: string) { ... },
};

// AutomatedSecretRotationService.ts
import secretManagementService from '@/services/secretManagementService';


C) Add a defensive shim so crashes never recur

import * as SecretModule from '@/services/secretManagementService';

const getSecret =
  (SecretModule as any).getSecret ??
  (typeof (SecretModule as any).default === 'function' ? (SecretModule as any).default
   : (SecretModule as any).default?.getSecret);

const getSecretMetadata =
  (SecretModule as any).getSecretMetadata ??
  (SecretModule as any).default?.getSecretMetadata;

if (typeof getSecret !== 'function' || typeof getSecretMetadata !== 'function') {
  console.warn('[secrets] getSecret/getSecretMetadata not available — rotation will be skipped');
}

async function safeRotateSecrets() {
  try {
    if (typeof getSecret !== 'function') return;
    // ... your rotation logic
  } catch (e:any) {
    console.warn('[secrets] rotation failed:', e?.message || e);
  }
}
